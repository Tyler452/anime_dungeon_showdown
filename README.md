This game would be categorized as an indie, shooter, action, adventure game. You will first start into a small lobby, and you would have to pick two different characters. Each one as their own special ability and starter weapon and when you enter the dungeon and when you enter the there will be enemies and chest to find with new weapons. This would be more of a demo with at least 2 levels just to get the feel of the game and see if people will like it during the capstone festival.

This game is meant to have fun making and have fun seeing people testing it.
